# Hasan Sammour Portfolio (React + Vite + Framer Motion, English / Arabic)

    npm install
    npm run dev       # http://localhost:5173
    npm run build

## Before you run it
1. Put your certificate files in `public/certificates/` (same names as your folder).
   Add the Gaza Sky Geeks one as `Gaza-Sky-Geeks-Zendesk-Support.png`.
2. Replace `public/hasan.png` with your suit-edited portrait (same name).
3. Contact form: copy `.env.example` to `.env`, get a free key at web3forms.com, paste it.
   Without a key the form opens the visitor's mail app instead.
4. All text (English + Arabic) lives in `src/data.js` and `src/i18n.js`.
